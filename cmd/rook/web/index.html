What is rook?

rook is mission control for your AI coding agents — watch every session, get pulled in when one needs you, and drive them. All local, read-only to GitHub.

busy — working now
waiting — needs your input
idle — waiting for a prompt
shell — in a shell command
dead — process exited

Tabs: Sessions (all agents) · Usage (5h/weekly + trends) · Dev servers · Workspace (skills/plugins/MCP) · Audit (commands + files changed) · GitHub (browse + spawn agents on issues/PRs).

Control features (Allow/Deny, live Terminal, Spawn) run agents in tmux so rook can drive them.

Shortcuts (on the selected waiting agent): a allow · d deny · 1–9 menu option.

Agent support: Claude Code is fully supported. Codex, Aider & Gemini are β — detection is best-effort and unverified against real session data (marked with a β chip).
