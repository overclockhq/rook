What rook does

One screen. Every agent. Full control.

Never babysit a terminal

Know what every agent is actually doing

A live roster that triages for you — who's blocked, who's looping, who's done — in plain English, with a desktop or phone ping the second one needs you.

  • Live status + situation report per agent
  • Stuck & loop watchdog
  • Allow / Deny right from the list
Diff-first review

Comment on the diff — the agent gets it

Read the canonical PR diff in-app, drop a comment on any line, and rook types it straight into the agent's session as a tracked thread. No copy-paste, no lost context.

  • Canonical PR diff, split or unified
  • Threaded comments that survive restarts
  • Nudge an agent that missed one
Context, in-app

Full PR & issue context without leaving

For any review agent, see the PR's description, commits, linked issues, reviews, and comments — pulled live from GitHub, right beside the diff.

  • Live PR / issue timeline
  • Start work or review from a ticket id
  • Open a PR from the agent's branch
Follow the money

Know where your tokens & cost go

Per-model and per-project cost, 5-hour and 7-day windows, a 30-day activity trend, and a quality score per run — so you can see which agents are worth it.

  • Cost by model & project
  • Quality × cost per session
  • Your top runs by spend
